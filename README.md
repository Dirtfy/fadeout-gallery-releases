# Fadeout Gallery — APK releases

이 저장소에는 Fadeout Gallery(페이드아웃 갤러리) Android 앱의 **설치 파일(APK)과 릴리스 노트만** 올라갑니다.
소스 코드는 비공개 저장소에서 관리합니다.

- 최신 버전: [Releases → Latest](https://github.com/Dirtfy/fadeout-gallery-releases/releases/latest)
- 앱(v0.2.1 이상)은 실행할 때 이 저장소의 최신 릴리스를 확인하고, 새 버전이 있으면 업데이트 팝업을 띄웁니다.
- 모든 APK는 같은 키로 서명됩니다. 그래서 기존 앱을 지우지 않고 덮어쓰기로 설치되며, 데이터도 유지됩니다.
  인증서 SHA-256: `e6:4d:c6:18:6c:af:d4:a5:b9:32:96:09:3e:7e:75:88:28:37:9c:f9:b2:9c:bd:32:fc:0b:ae:77:ce:62:97:d8`

---

This repository holds only the signed APKs and release notes for the Fadeout Gallery
Android app (source is private). The app's in-app updater reads
`releases/latest` from here.
